一台电脑开服

  1. 主机安装 Node.js 20 或更高版本。
  2. 完整解压服务包，Windows 双击 启动局域网服务.cmd；Mac / Linux 运行 sh start-racing-lan.sh。
  3. 保持开服窗口运行，网页会显示主机 IP。选择赛道与人数，创建房间。

好友直接输入 IP

连接同一 Wi-Fi / 有线网络，浏览器输入：

http://192.168.1.23:8790

把示例 IP 换成主机显示的地址。进入大厅后点击房间旁的「加入」，房主发车即可。好友只需要浏览器，无需安装环境。

停止、配置和连接帮助

关闭开服窗口或按 Ctrl+C 停止。编辑 racing-server.config.json 可改端口，修改后重启。

无法连接时检查：双方同一网络、服务窗口仍在运行、主机防火墙允许当前专用网络，以及路由器未隔离设备。多个 IP 时选择当前 Wi-Fi / 有线网卡。不要为服务配置公网端口映射。
