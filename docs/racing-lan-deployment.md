# 逐浪竞速 · 局域网服务部署包 v1.1.1

这是可独立运行的服务部署包，已包含游戏页面、两条赛道、服务器和全部 JavaScript 依赖。只需一台电脑开服，其他玩家使用浏览器，不需要安装游戏或 Node.js。支持最多 16 人个人或红蓝组队竞速，空位由 AI 自动补齐。

## 主机：首次部署

1. 在开服电脑安装 Node.js 20 或更高版本：[官方安装页](https://nodejs.org/)。已经安装则跳过。
2. 将 ZIP **完整解压**到一个文件夹，不要在压缩包内直接启动。
3. Windows 双击 **启动局域网服务.cmd**。Mac / Linux 在解压目录运行 **sh start-racing-lan.sh**。
4. 浏览器自动打开本机大厅。主机窗口和页面都会显示内网 IP，例如 **192.168.1.23:8790**。如有多个地址，选择当前 Wi-Fi / 有线网卡对应的地址。
5. 在大厅选择赛道、个人/红蓝组队、人数、圈数与 AI 难度，点击「创建房间」。

## 好友：直接连接 IP

1. 与主机连接同一 Wi-Fi 或有线局域网。
2. 浏览器直接打开 **http://主机IP:8790**，例如 **http://192.168.1.23:8790**；或在人机版的「局域网」页输入 **192.168.1.23:8790**，点击「连接主机」。
3. 进入主机大厅后，看到房间列表，点击「加入」。无需房间码。房主点击「开始比赛」即可发车。
4. 指定房间也可复制邀请链接给好友，直接定位房间。

只由主机电脑安装 Node.js。好友不需要运行任何服务，也不需要 CDN 或互联网连接：整套游戏资源随服务包提供。

## 停止与修改配置

保持开服窗口运行，电脑保持在线。按 Ctrl+C 或关闭窗口停止服务，所有联机玩家随即断开；人机版仍可独立游玩。重启后房间重新创建，不保存上次对局。

编辑根目录 **racing-server.config.json** 后重启：
- port：默认 8790。若端口冲突改为 8791，好友地址也使用 :8791。
- host：默认 0.0.0.0，允许局域网连接；127.0.0.1 只允许本机。
- maxRooms：同时最多 1–8 个房间，默认 8；每个房间最多 16 人。

也可运行 node scripts/racing-server.mjs --port 8791 临时指定端口。游戏设置在网页内选择。

## 连接不成功

- 主机网页可用、好友访问超时：检查防火墙是否允许 Node.js 在当前专用网络接收连接；若首次提示，允许当前专用网络即可。程序不会自动更改防火墙。
- 检查双方是否同一网络；访客 Wi-Fi、校园网和开启设备隔离的路由器可能阻止设备互访。
- 有多个 IP：使用当前 Wi-Fi / 有线网卡的 IPv4，不使用 VPN / 虚拟网卡地址。
- 端口占用：先关闭重复开服窗口，或修改配置中的 port 后重试。
- 浏览器自动打开失败：手动访问 http://localhost:8790。
- CDN 人机页上的 IP 连接会跳转到主机提供的本地页面，再建立同源比赛连接。
- 此服务用于可信局域网，无公网账号体系；不要在路由器上为它配置公网端口映射。

## 操作与比赛

W / ↑ 油门，A D / ← → 转向，S / ↓ 刹车；Shift 漂移，Space / Ctrl 氮气，C 镜头，R 复位，Esc 暂停自己的操作。支持触屏。
真人入场自动替换 AI；掉线后 AI 接管，房主离开则移交下一位好友。局域网比赛不因某位玩家暂停而停止。

完整游戏源码同样包含于包内 games/apex-rush/ 和 scripts/racing-server.mjs；额外的验证测试在完整源码包中。Three.js 与 ws 使用 MIT 许可证，文本随包提供。本作是独立制作的经典赛道风格致敬，非腾讯官方游戏。
